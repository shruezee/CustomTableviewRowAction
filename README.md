# CustomTableviewRowAction

**Swipe-to-reveal table row actions with icons, custom fonts, borders, and colours**, beyond what the default `UITableViewRowAction` offers.

## What it demonstrates

- Row actions that show an **icon and a title**, rendered into a single image
- A **dynamic action width** calculated from the title text
- Optional borders, per-action background colours taken from the table, and custom fonts
- A reusable helper (`CustomTableViewRowAction.swift`) that builds the icon-and-text image, so it can be dropped into any table

## Running it

Open `CustomTableviewRowAction.xcodeproj` in Xcode, run on a simulator, and swipe left on a row.
